Why

I wanted one place under my own name and domain that I control, and that I can move to another host without rebuilding it.

  • torresmarcos.com: it was available, it won't age, and it's a .com.
  • Cloudflare: I compared it with Porkbun and picked Cloudflare for the extra customisation and control, even though it ties the domain to its own DNS.
  • Plain HTML and CSS: I considered Astro, but plain HTML is simpler for now and easy to migrate later.
  • GitHub Pages: it's free, and a site this light doesn't need more.
  • Text first: I wrote the content before working on the look, because the design depends on what it has to hold.

What I learned

I had never used GitHub Pages before this.

  • How to serve a repository from a custom domain on GitHub Pages.
  • What A and CNAME records do: four A records point the bare domain to GitHub's servers, and a CNAME points www to my GitHub Pages address. I set them up in Cloudflare.
  • How to turn on Enforce HTTPS so every visit goes over a secure connection.
