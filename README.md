# torresmarcos.com

My personal website: [torresmarcos.com](https://torresmarcos.com).

## Structure

Plain HTML, one file per page:

- `index.html`: home page with a short about me
- `uses.html`: what I use
- `projects.html`: my projects

## View it locally

Open any of the HTML files in a browser by double-clicking it. Links such as `/uses` only work on the published site.

## Add a project

Copy an existing project block in `projects.html` (from `<h2>` to `</ul>`) and fill it in: what it is, why, built with, what I learned and a link to the code.
